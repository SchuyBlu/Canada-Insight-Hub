# Canada Insight Hub 

This project exists to live as a hub for StatCan data, primarily with
visualization in mind.

## Installation

You will need to update the values within `.env.example` and rename to `.env`. Otherwise, the only other potential hangup in the installation process exists if you are contributing. Otherwise, just run via the compose file.

For development, you'll need to install `python3-dev` and `libpg-dev` for `psycopg2` to correctly install.
