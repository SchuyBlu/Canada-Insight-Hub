# Data

All data sources are outlined below for the project. Data will not be pulled
via HTTP as sources are not updated as live information. Files will not
be uploaded to github due to storage limitations.

It will be up to you to download the files from the sources provided
and to add them to the data folder. This may not be ideal, but is the best
way I know how to share an open source data project without hosting the data.

## Sources

- [NOC Classification](https://www.statcan.gc.ca/en/subjects/standard/noc/2021/indexV1)
